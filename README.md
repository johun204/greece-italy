## 여행 중 쓰는 기능

- **하단 빠른 메뉴** — 엄지 닿는 곳에 `‹ 이전 · 📍오늘 · 📌근처 저장 · 💶환율 · 🚨긴급 · 다음 ›`. 환율·긴급은 화면 아래에서 올라오는 시트(✕ 또는 본문 탭으로 닫힘).
- **지금 / 다음 카드** — 오늘 페이지 맨 위에 ‘지금 하는 일’과 ‘다음 일정(몇 분 후)’ + **🧭 다음 장소 길찾기** 버튼. ‘시간표에서 보기’로 해당 행까지 이동.
- **📌 저장해 둔 곳** — 구글맵 리스트 78곳을 도시별(아테네/산토리니/로마)로. 📅 = 일정에 넣은 날, ‘일정에 넣은 곳만’ 필터, **📍 가까운 순**(GPS). 하단 ‘근처 저장’은 보고 있는 날의 도시로 바로 열림.
- **짧아진 헤더** — 날짜 칩 한 줄(나라·도시 구분선 포함). 일자 소개문은 첫 문단만 보이고 배경 설명·오늘 경비는 ‘더보기’로 접힘(PDF/인쇄 땐 자동 펼침). 지도는 시간표 아래(폴드 펼침·태블릿은 오른쪽 고정).
- **식당 후보마다 🗺️ 지도 · 🧭 길찾기**, 저장 리스트에 있던 곳은 `⭐저장` 표시.
- **한눈에 보기** — 상단 첫 칩. 14일 전체를 날짜별로 굵직한 일정·✅예약완료·⏳예약 필요·🏨숙소로 한 페이지에 정리(행을 누르면 그날 상세로). 예약완료만 표시하고, 예약·확인 필요 항목은 준비 페이지에 나옵니다. 상태는 `build.js`의 `OV` 배열에서 고칩니다.
- **상단 메뉴 접기** — 헤더 오른쪽 ▲/▼ 로 날짜 칩 줄을 접고 펼침(상태 기억).
- **오늘 자동 이동** — 앱을 열면 그날 페이지 맨 위(지금/다음 카드)가 바로 뜹니다. 여행 전이면 준비 페이지(D-day + 날짜별 ⏳예약이 맨 위). 하단 **📍오늘**으로 언제든 복귀.
- **“지금” 표시** — 현재 시각이 지난 마지막 일정 행에 주황 띠 + `지금` 배지. 1분마다, 화면 복귀 때마다 갱신.
- **내 위치** — 지도 아래 **📍 내 위치** → GPS 실시간 추적(파란 점 + 정확도 원). 켜두면 동선 칩마다 **현재 위치에서의 거리**가 붙고, 가장 가까운 지점을 알려줍니다. 한 번 켜면 다음 실행에도 자동. GPS라 오프라인에서도 동작.
- **길찾기** — 모든 장소에 **🧭 길찾기**(현재 위치 → 그 장소, 구글지도 앱으로 바로), 마커 팝업에도 동일. 지도 아래 **이 날 동선 전체 길찾기**는 경유지까지 넣은 통짜 경로.
- **환율 · 원화 병기** — 하단 💶 → 1€당 원화 입력(기본 ₩1,591, 2026-09-20 시장환율, 기기에 저장) + €↔₩ 계산기. 본문의 모든 `€` 금액 옆에 `(₩…)`가 자동으로 붙고, 환율을 바꾸면 즉시 갱신됩니다.
- **폴드 대응** — 접으면 1단, 펼치면 **좌 일정 / 우 고정 지도** 2단(≥700px). 접기·펼치기 때 지도 크기와 보던 페이지를 그대로 유지합니다. 힌지가 있는 기기(`horizontal-viewport-segments: 2`)는 가운데 여백을 더 줍니다.

> 지도 라이브러리는 **Leaflet**, 타일은 **OpenStreetMap** — 둘은 대체 관계가 아니라 이미 같이 쓰는 조합입니다(교체 불필요).

## 오프라인 동작

- 모든 텍스트·체크리스트·회화·**날짜별 개략 동선도(SVG)**는 네트워크 없이 그대로 표시.
- 온라인일 때 연 지도(OpenStreetMap 타일)는 그 구역만 캐시되어 이후 오프라인에서도 보임.
- 상단 **⬇︎** 버튼 → 모든 탭 펼친 인쇄본 저장 (지도 포함). `greece-italy-honeymoon.pdf`는 미리 만들어 둔 백업본.

## 갱신

`index.html`은 `build.js`로 원본(`greece-italy-honeymoon-2026.src.html`)에서 생성됩니다. 고치고 나면 `node build.js && node test.js`.
서비스워커 캐시 버전은 `sw.js`의 `APP_CACHE` 값을 올리면 강제 갱신됩니다.

지도 캡처(인쇄/오프라인용 `map-*.png`)는 `node mkmapshot.js`로 `mapshot.html`을 만든 뒤 헤드리스 크롬으로:

(프록시 환경에서 크롬이 타일 인증서를 거부하면, 타일/unpkg를 로컬 http 중계로 받아 Playwright 820×470 뷰포트로 캡처 — 2026-10 갱신분이 이 방식)

```
chrome --headless=new --disable-gpu --hide-scrollbars --virtual-time-budget=12000 \
  --window-size=820,470 --screenshot=map-2.png "file:///…/mapshot.html?d=2"
```

⚠️ `build.js`의 `RUNTIME`은 **템플릿 리터럴**입니다 — 안에 정규식을 쓸 땐 백슬래시를 두 번(`\\d`) 써야 산출물에 `\d`로 남습니다. `test.js`가 이 경우를 잡아줍니다.
